# 01 — 连续挂单直到收盘时刻

**What to build:** 每个合约会话在每轮"成交→撤单→对账→受限 FAK 平回零仓"完成后自动继续挂单，直到停止条件生效：配置的 `session_end_time`（本地时钟 HH:MM，到点走与操作员中断相同的收口链路）、`max_round_trips` 轮数上限（默认 10，正常停止）或操作员中断。任何收口/平仓失败仍立即 FAILED，绝不带仓重挂；非收口状态下的迟到成交必须立即触发新一轮收口。审计摘要新增 `round_trips` 与 `stop_reason`。

**Blocked by:** None — can start immediately

**Status:** ready-for-agent

- [x] 配置层支持 `session_end_time`（HH:MM 校验、默认空=不限）与 `max_round_trips`（正整数、默认 10），公共参数级共享。
- [x] 轮完成净仓归零后清锚、重过稳定行情门槛、按当前价重新挂双侧报价；轮与轮以稳定门槛为冷却。
- [x] `max_round_trips` 用尽在当前轮完成后正常停止（FINISHED + `stop_reason=max_round_trips`）。
- [x] `session_end_time` 到点：报价/换挡中会话走收口链路；未报价会话直接正常终态；已过当日时刻不再发首笔报价；`stop_reason=session_end`。
- [x] 稳定等待期迟到成交（上一轮撤单竞速失败）立即触发新一轮收口并对账权威净仓。
- [x] 摘要含 `round_trips`/`stop_reason`；单轮收口旧测试以 `max_round_trips=1` 适配；端到端假网关测试同步适配。
- [x] SimNow 实盘验收：一个交易时段内完成 ≥2 轮成交平仓续挂，到点或轮数上限正常停止。

> 完成记录（单元与端到端部分）：全套 61 个测试通过。决策依据 ADR 0003；词汇见 CONTEXT.md「单轮成交收口」「收盘停止」「往返轮数上限」「迟到成交触发」。
>
> **事故附录（2026-08-14 夜盘，与本特性相关）**：连续多 run 测试中，驱动脚本被强制终止（进程组 SIGKILL）导致一个仍在收口的实盘进程被杀，MA609 卖单随后在交易所侧成交遗留空仓 1 手；已用受控 FAK 脚本买平 @2678 恢复零仓（往返亏 2 跳）。教训：停止实盘进程必须先 SIGINT 等待优雅收口退出，绝不可杀进程组；连续模式下"到点自动收口"（本特性）正是消除此类人工时序风险的手段。

> 审查修复（code-review 双轴）：①操作员中断期间完成的轮不再续挂（stop_reason 先到者优先，max_round_trips 不得覆盖 interrupted/session_end）；②迟到的平仓成交若实际改变净仓，立即触发新一轮收口（原先静默忽略违反「绝不带仓重挂」）；③收口对账查出非零仓时补记该轮（防撤单竞速成交漏计轮数）；④收口态集合常量化、迟到成交分支死代码清除、跨午夜测试加固。修复后全套 64 个测试通过。
