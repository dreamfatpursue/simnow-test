# 01 — 多合约策略配置解析

**What to build:** 策略配置升级为多合约格式：顶层保留全部合约共用的网格与安全参数，新增按合约条目列表（合约、交易所、每侧手数）。加载后能为每个合约生成一份自洽的单合约会话配置（公共参数注入），整份生效配置计算唯一的策略哈希身份。格式非法、合约列表为空、条目缺字段、同一合约重复出现、手数非正都要给出指明字段和条目的清晰错误；旧的单合约扁平格式被拒绝时提示迁移方式。

**Blocked by:** None — can start immediately

**Status:** ready-for-agent

- [ ] 多合约配置文档能被加载，每个合约条目得到一份含公共参数的单合约会话配置。
- [ ] 整份生效配置只有一个 SHA-256 策略哈希身份，与逐合约配置关联可追溯。
- [ ] 空合约列表、重复合约、缺失字段、非正手数等非法输入的报错明确指向具体条目和字段。
- [ ] 旧单合约扁平格式被拒绝，报错包含迁移指引。
- [ ] 配置解析与校验有单元测试覆盖合法与非法用例。
