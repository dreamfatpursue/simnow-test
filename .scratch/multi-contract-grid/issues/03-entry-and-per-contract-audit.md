# 03 — 多合约入口编排与按合约审计

**What to build:** 实盘入口一次启动多合约运行：从多合约策略配置构建全部单合约会话与单一共享适配器；主循环等待每个会话各自到达终态后结束运行；操作员中断广播给全部会话，各走自己的人工结束收口。审计目录按合约分子目录，各自保留无凭证生效配置、CTP 事件流与最终安全摘要；运行根目录另写一份全合约汇总摘要，列出每个合约的终态、净持仓、活动委托与失败。

**Blocked by:** 02 — 适配器多会话路由与持仓查询扇出

**Status:** ready-for-agent

- [ ] 入口从多合约配置构建与配置条目一一对应的会话集合，共享单一适配器。
- [ ] 运行在全部会话终态后结束；单合约先收口不影响其余合约继续报价。
- [ ] 操作员中断广播至全部会话，每个会话完成各自撤单与收口后才退出。
- [ ] 审计目录每合约一个子目录，结构与单合约时代一致，合约间事件不混写。
- [ ] 运行根目录的汇总摘要逐合约列出终态、净持仓、活动委托与失败，可据此还原整次运行。
- [ ] 假网关端到端测试跑通多合约启动、单合约收口、中断广播，并核对审计产物。
