# 02 — 适配器多会话路由与持仓查询扇出

**What to build:** CTP 适配层同时服务多个单合约会话：持有合约到会话的映射，订阅全部目标合约；合约元数据、行情、委托、成交事件按事件携带的合约路由到对应会话，跨会话委托号隔离不撞号；会话产出的提交、撤单等动作由对应会话分发出站。持仓查询仍发起一次账户级查询，完成事件由适配层按合约拆分广播给每个会话做零仓启动门槛；任一目标合约净仓非零时整个运行拒绝，一张单都不发。

**Blocked by:** 01 — 多合约策略配置解析

**Status:** ready-for-human

- [x] 适配层订阅并路由全部目标合约的合约元数据与行情，非目标合约事件被忽略。
- [x] 两个合约的委托与成交回报各自路由到本合约会话，互不串扰；委托号跨合约不冲突。
- [x] 任一会话的下单动作携带本合约信息正确出站，多会话交替动作不混流。
- [x] 一次账户级持仓查询完成后，每个合约会话各收到本合约净持仓的完成事件，持仓查询关联号语义保持不变。
- [x] 任一合约非零仓导致整运行拒绝且无任何委托发出；全为零仓时各会话独立放行。
- [x] 假网关集成测试覆盖两合约并行挂单、单合约成交回报路由与持仓扇出。

> 完成记录: 提交 97b3296 + 审查修复 f0673d1。审查后补充：零仓门槛改为全局时钟门控（全部会话过门槛前禁止任何会话首次报价），拒绝时向全部会话（含未评估合约）广播中断；全部网关回调在适配器锁内变更共享状态。委托号隔离依赖网关自增 OrderRef + 按 symbol 路由（见 ADR 0002）。
