# 04 — 多合约 SimNow 实盘验收

**What to build:** 用两个真实 SimNow 合约完成多合约运行的实盘验收：启动后两合约同时进入稳定行情挂单；其中一合约首次成交后仅该合约走单次成交收口并停止，另一合约不受影响继续报价直至自行终态或被操作者中断收口；另预先让一个合约带非零持仓启动，验证整个运行被拒绝且无任何委托发出。每次运行从审计目录的合约子目录与根目录汇总确认各合约终态、净持仓为零、无遗留活动委托。

**Blocked by:** 03 — 多合约入口编排与按合约审计

**Status:** ready-for-agent

- [ ] 完成一次两合约同时挂单的 SimNow 运行，两合约事件流在各自审计子目录中完整独立。
- [ ] 完成一次单合约首次成交验收：成交合约独立收口平仓，另一合约不受牵连。
- [ ] 完成一次非零仓拒绝验收：任一合约有持仓时整运行拒绝启动且未发单。
- [ ] 完成一次操作员中断验收：全部合约会话各自收口，无遗留活动委托。
- [ ] 每次运行的根目录汇总摘要与各合约子目录核对一致，全部合约净仓为零或残余风险显式记录。
