# 05 — 行情重定锚与恢复确认

**What to build:** LastPrice 持续越出当前价格带达到确认时间后，系统按十 tick 步长重定锚；行情无效或盘口过宽时暂停报价，行情恢复有效后必须重新通过两秒稳定门槛。

**Blocked by:** 04 — 稳定行情门槛与首轮 W/D/S 报价

**Status:** ready-for-agent

- [ ] LastPrice 只在持续越出当前价格带达到配置确认时间后触发重定锚，短暂越界不会触发替换。
- [ ] 新锚点按十 tick 步进，并足以使价格带重新覆盖当前有效价格；生成价格保持 tick 对齐。
- [ ] 无效行情或盘口保护失败会暂停新的报价，并对已有测试报价启动安全处理。
- [ ] 行情恢复后必须重新累计两秒连续有效且受保护的快照，不能直接恢复报价。
- [ ] 重定锚只产生可观察的替换意图，不以行情穿价推断成交。
