# 01 — CTP 项目依赖与持仓查询完成契约

**What to build:** 项目使用可追踪的 CTP 网关源码；每次持仓查询都会产生带 `request_id` 的完成事件，查询无持仓时也明确产生空结果，供实时网格的零仓启动和收口查仓使用。

**Blocked by:** None — can start immediately

**Status:** ready-for-agent

- [ ] 运行时可验证使用项目管理的可编辑 CTP 网关；订单能力入口发现未管理的网关时硬失败。
- [ ] 每次持仓查询都会向调用方暴露可关联且递增的请求标识。
- [ ] 有持仓记录和无持仓记录的查询都会发布公开的持仓查询完成事件，并携带发起该查询的请求标识和汇总结果。
- [ ] 不依赖真实 CTP 连接的确定性适配测试覆盖有结果和空结果两种情况。
