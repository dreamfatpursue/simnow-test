# 02 — 策略配置、哈希预览与 SimNow 确认入口

**What to build:** 操作者可以加载不含凭证的版本化策略配置，查看标准化目标合约、手数、W/D/S 和安全参数，并获得确定性哈希；只有显式 SimNow 确认时，入口才允许进入可下单模式，哈希仅用于展示、审计和复盘识别，原只读连接入口继续保持只读。

**Blocked by:** None — can start immediately

**Status:** ready-for-agent

- [ ] 策略配置只包含目标合约、交易所、目标委托手数、W/D/S 和安全参数，不接受 CTP 凭证或前置地址。
- [ ] 配置校验拒绝无效交易所、非正手数、非正安全参数和不完整字段，并生成明确的标准化有效配置。
- [ ] 预览展示目标合约、交易所、手数、W/D/S、报撤限额、撤单终态等待上限和平仓边界。
- [ ] 对标准化配置生成确定性 SHA-256，并写入预览与审计；缺少 SimNow 确认时只能预览，哈希不参与委托授权。
- [ ] 原普通连接命令仍不会发送委托或撤单。
