# 03 — 合约元数据与关联零仓启动门槛

**What to build:** 实时网格只使用策略配置中的目标合约；在收到匹配的合约元数据、正数 `pricetick`、本次启动查询的持仓完成事件，并确认目标合约净仓为零之前，不提交任何开仓委托。

**Blocked by:** 01 — CTP 项目依赖与持仓查询完成契约；02 — 策略配置、哈希预览与双确认入口

**Status:** ready-for-agent

- [ ] 会话忽略只读行情订阅中与策略目标不一致的合约，不会因此改变下单目标。
- [ ] 缺少目标合约元数据或 `pricetick` 非正时，始终保持不下单。
- [ ] 启动持仓查询的请求标识与完成事件不匹配时，完成事件不能打开零仓门槛。
- [ ] 目标合约显式返回空查询或净仓为零后，启动门槛才允许继续等待行情；非零目标净仓直接拒绝本次运行且不发送开仓委托。
