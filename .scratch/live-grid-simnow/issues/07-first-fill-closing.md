# 07 — 首次成交触发单次成交收口

**What to build:** 任一开仓委托首次部分或全部成交后，系统永久停止新报价，撤销所有剩余测试委托并记录迟到的订单、成交回报；不会因为部分成交或另一侧委托仍未成交而继续扩大敞口。

**Blocked by:** 06 — 安全替换、订单终态与报撤限流

**Status:** ready-for-agent

- [ ] CTP 成交回报首次报告部分成交或全部成交时，立即进入单次成交收口并永久禁止该运行再次开仓报价。
- [ ] 收口会撤销所有剩余测试委托，包括未成交的相反方向报价。
- [ ] 收口期间接受并记录迟到的委托、撤单和成交回报，不恢复报价或重复开启测试周期。
- [ ] 只有 CTP 订单和成交回报能触发成交收口；行情穿价、定时器或预期成交量不能触发收口。
- [ ] 收口动作对部分成交和全部成交都能形成明确、可继续查仓的终态。
