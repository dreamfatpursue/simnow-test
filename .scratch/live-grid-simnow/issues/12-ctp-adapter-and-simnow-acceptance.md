# 12 — 真实 CTP 适配与 SimNow 分阶段验收

**What to build:** 将真实 CTP 合约、行情、委托、成交、持仓查询完成事件和中断信号接入实时网格会话，并验证运行时加载项目内 CTP 依赖；完成远价无成交中断、受控首次成交、拒单、撤单超时和平仓不完整等阶段性验收。

**Blocked by:** 11 — 测试审计目录与最终安全摘要

**Status:** ready-for-agent

- [ ] CTP 适配层将真实回调转换为会话需要的标准化事件，并将会话动作转换为提交委托、撤单和持仓查询请求。
- [ ] 适配层使用并验证项目管理的 CTP 网关；缺少持仓查询完成契约时，订单能力入口硬失败。
- [ ] 真实适配不改变普通连接命令的只读行为，且不会把行情穿价转换为成交事件。
- [ ] 完成一次远离市场、无成交后由操作者中断的 SimNow 验收，审计结果明确显示无遗留活动委托和净仓。
- [ ] 完成一次受控首次成交验收，并观察拒单、撤单终态超时和平仓不完整等失败场景；每次结果都能从最终摘要确认终态和残余风险。
