# 08 — 人工中断复用收口路径

**What to build:** Ctrl+C 或等价进程中断在报价、替换或已进入收口时都进入同一条撤单、查仓和受限平仓流程，不直接断开连接，也不遗留已跟踪的活动委托。

**Blocked by:** 07 — 首次成交触发单次成交收口

**Status:** ready-for-agent

- [ ] 报价或替换阶段收到中断后，系统停止新报价并发起必要的测试委托撤单。
- [ ] 已有活动委托或已确认非零仓位时，中断不会直接关闭 CTP 连接或把运行标记为成功结束。
- [ ] 中断路径等待订单回报并进入后续关联查仓；其状态转换和动作语义与首次成交收口一致。
- [ ] 重复中断不会重复开启收口、重复提交新开仓委托或绕过风险状态。
- [ ] 无活动委托且确认无仓时，中断可以形成明确的安全结束结果。
