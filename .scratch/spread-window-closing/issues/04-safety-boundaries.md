# 04 — 安全边界适配

**What to build:** 价差窗口收口下的全部安全边界有测试背书：无窗口配置、窗口内操作者中断、窗口与平仓期间的迟到开仓成交、部分成交净仓算术，以及旧语义用例的完整改写。

**Blocked by:** 02 — 配置项与窗口主路径；03 — 价差完成分支

**Status:** ready-for-agent

- [ ] `closing_wait_seconds=0` 表示无窗口：首次成交直接按净仓 FAK 平仓、平仓终态后撤对侧，与超时路径一致。
- [ ] 窗口期间操作者中断走人工结束收口：撤全部委托、等终态、查仓、有净仓则受限 FAK。
- [ ] 窗口或 FAK 执行期间的迟到开仓成交触发新一轮收口，不被忽略；净仓翻向时按翻向后的净仓平仓。
- [ ] 部分成交按净仓算术处理，对账查仓结果为权威净仓。
- [ ] 旧"首成交立即撤单收口"的全部既有用例改写完毕；安全不变量（每轮结束无遗留委托、无遗留仓位、失败显式残留、不带仓重挂）在新语义下全部有断言。
