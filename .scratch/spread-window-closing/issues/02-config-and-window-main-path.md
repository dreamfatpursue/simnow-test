# 02 — 配置项与窗口主路径

**What to build:** 新增 `closing_wait_seconds` 策略配置（默认 1、允许 0、进 canonical JSON 与哈希）；首次成交不再撤对侧而是进入等待窗口，窗口超时后按净仓走受限 FAK 平仓，平仓终态后撤对侧，全部终态并对账净仓为零才完成本轮。

**Blocked by:** None — can start immediately

**Status:** ready-for-agent

- [ ] `closing_wait_seconds` 进入策略配置：默认 1，非负校验，非法值拒绝；canonical JSON 与策略哈希反映该字段。
- [ ] 任一报价首次部分或全部成交后，状态机进入等待窗口，不撤销对侧报价，不发起对账查仓。
- [ ] 窗口计时由时钟事件推进；超时后按当时净仓执行受限 FAK 平仓（3 秒 / 10 tick 重价规则不变）。
- [ ] FAK 平仓终态后才撤销对侧报价；撤单终态后发起关联对账查仓，净仓为零才判定本轮完成并进入下一轮或停止。
- [ ] 受限 FAK、撤单终态上限、收盘停止、往返轮数上限等既有规则原样保留。
- [ ] 会话测试按事件驱动接缝覆盖主路径的动作序列与终态；既有"首成交立即撤单"用例按新语义改写，安全不变量断言（无遗留委托、不带仓重挂）保留。
