# 03 — 价差完成分支

**What to build:** 等待窗口内对侧报价成交时，本轮以价差完成直接收尾：立即结束窗口，两侧委托全部终态后对账查仓，净仓为零即完成本轮，全程不产生任何平仓动作。

**Blocked by:** 02 — 配置项与窗口主路径

**Status:** ready-for-agent

- [ ] 窗口内对侧成交（部分或全部）立即结束等待，不等满窗口时长。
- [ ] 价差完成分支不发出任何 FAK 平仓或撤单动作（两侧委托均已成交终态）。
- [ ] 全部委托终态后发起关联对账查仓，净仓为零判定本轮完成。
- [ ] 对账净仓非零时按主路径的 FAK 平仓序列处理（对侧部分成交留下的残余净仓）。
- [ ] 会话测试覆盖：双边全部成交、双边部分成交残余净仓两种场景的动作序列与终态。
