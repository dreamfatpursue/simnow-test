# 04 — 报告骨架：轮次重建与交易日归组

**What to build:** 新增离线报告命令：扫描审计根目录，按交易所交易日（CTP 交易日口径，夜盘归入下一交易日）聚合当日全部 run，按合约重建每轮往返记录（成交委托的报单时刻/价格/数量 → 成交时刻/价格/数量 → 平仓时刻/价格/数量），生成自包含单文件 HTML。这是整个"交易日成交明细"的 tracer bullet。

**Blocked by:** 02 — 事件补记交易所时间与合约乘数

**Status:** ready-for-agent

- [ ] 命令支持指定交易日生成与全量生成，`--open` 生成后自动在浏览器打开，输出到 reports 目录。
- [ ] 交易日按成交回报内的交易所日期归组，夜盘成交自动归入下一交易日的文件；不依赖 run 目录名（UTC）推断。
- [ ] 每条记录是一轮往返中成交委托的完整生命周期：报单时刻/价格/数量、成交时刻/价格/数量、平仓时刻/价格/数量；同轮被撤委托不出现。
- [ ] 部分成交按净仓配对成轮；一轮内多笔平仓成交合并展示（总量、加权均价、首末时刻）。
- [ ] 开平仓委托沿用 client_id 前缀约定识别，不新增字段。
- [ ] 缺交易所时间戳的历史 run 无法归入交易日，跳过并在命令行提示跳过数量。
- [ ] HTML 为纯静态表格单文件，无外部 CSS/JS 依赖。
- [ ] 测试以"合成审计目录进 → HTML 文件出"为唯一接缝，覆盖夜盘归组、多轮往返、部分成交、多笔平仓合并、多合约并发、旧 run 跳过。
