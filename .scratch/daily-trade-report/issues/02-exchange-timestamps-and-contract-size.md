# 02 — 事件补记交易所时间与合约乘数

**What to build:** 实时链路把 CTP 委托/成交回报自带的交易所时间（报单时间、成交时间）与合约乘数随事件落进测试审计目录，让审计事实足以回答"几点挂的单、几点成交的、每手折多少钱"。不改变任何下单或收口决策。

**Blocked by:** None — can start immediately

**Status:** ready-for-agent

- [ ] 委托事件与成交事件携带可选的交易所时间字段，合约事件携带可选的合约乘数字段，默认值保持既有事件构造与测试兼容。
- [ ] 适配器从网关回报（而非自造时钟）传递报单时间与成交时间，从合约数据传递乘数。
- [ ] 新 run 的逐事件审计里能直接看到交易所墙钟时间与乘数。
- [ ] 会话测试、适配器测试、审计测试三处既有接缝各补断言：字段传递、落盘序列化、向后兼容。
