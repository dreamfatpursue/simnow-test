# 02 — 让命令行与控制台共用单活动运行准入

**What to build:** 无论操作员从命令行还是控制台发起已确认的交易运行，同一时刻都只能存在一个活动交易进程；发现已有运行时返回该运行身份而不再启动，进程退出后可直接开始下一次运行。

**Blocked by:** None — can start immediately.

**Status:** done

- [x] 已确认的交易启动会原子获得活动运行锁并记录无凭证运行身份，身份足以定位活动进程及其审计运行。
- [x] 第二个命令行或控制台启动请求在锁被持有时不会创建交易进程，而是明确报告已有活动运行。
- [x] 交易进程退出即释放锁；下一次已确认启动可继续执行，且不引入异常退出后的待核验门槛。
