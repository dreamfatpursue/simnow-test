# 05 — 展示审计派生的运行详情

**What to build:** 操作者可从活动运行的结构化审计中按合约查看报价依据、报价窗口、轮次、逻辑委托、真实成交、最近确认净仓和因果时间线，及时识别风险而不把页面变成盈亏看板或日志查看器。

**Blocked by:** 04 — 恢复活动运行概览。

**Status:** done

- [x] 每合约展示最新 Last、Bid1、Ask1、行情时间、当前报价窗口、轮次和最大轮次，并按该合约自身的行情过期阈值标示新鲜度。

- [x] 运行因果时间线、审计写入中的不完整尾行和新的风险事件均得到正确处理；页面仅对打开后首次进入的风险阶段发出提示，且不显示盈亏或解析原始终端文本。
