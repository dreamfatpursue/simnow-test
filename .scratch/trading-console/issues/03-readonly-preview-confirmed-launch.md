# 03 — 交付只读策略预览与一次确认启动

**What to build:** 操作者可通过固定本机命令打开控制台，选择现有策略文件和仿真环境，离线预览实际会使用的参数并完成一次确认后启动交易；已有活动运行时页面直接进入该运行。

**Blocked by:** 02 — 让命令行与控制台共用单活动运行准入。

**Status:** done

- [x] 控制台固定仅监听本机回环地址，启动时尝试打开默认浏览器并始终给出可手工访问的地址；非本机 Host 或 Origin 请求被拒绝。
- [x] 页面只能列出安全范围内的现有策略文件，完整展示复用现有规则得到的规范化参数、策略哈希、合约范围、报价窗口和不含值的环境缺项。
- [x] 一次确认只授权同一策略哈希、环境和历史行情许可启动一次；选择变化、源文件变化或服务重启后须重新预览，启动前再次核对并将原始策略文件交给交易进程。
