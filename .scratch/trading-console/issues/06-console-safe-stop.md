# 06 — 从概览页发起全合约安全停止

**What to build:** 操作者可从活动运行概览二次确认发起一次全合约人工结束收口；控制台只请求匹配活动身份的交易进程执行既有安全链路，并持续展示收口事实直至安全终态或进程异常退出。

**Blocked by:** 01 — 让 RISK_HOLD 中断进入不可逆安全收口；02 — 让命令行与控制台共用单活动运行准入；03 — 交付只读策略预览与一次确认启动；04 — 恢复活动运行概览。

**Status:** done

- [x] 操作员必须二次确认；控制台仅向活动锁和运行身份都匹配的交易进程发送一次中断，重复请求保持幂等。
- [x] 页面投影过期不会禁用安全停止；请求被受理与撤单、对账、FAK 平仓、零活动委托和零净仓的实际完成保持明确区分。
- [x] 中断后的概览持续显示每合约收口进度，并在普通运行与 `RISK_HOLD` 两种路径下验证最终不会恢复报价。
