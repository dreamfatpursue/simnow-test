# 04 — 恢复活动运行概览

**What to build:** 操作者可以在控制台重新打开后恢复正在执行的多合约运行概览，快速判断启动等待、交易运行、安全收口、风险或终态，而不会使浏览器或控制服务成为交易进程的生命周期所有者。

**Blocked by:** 02 — 让命令行与控制台共用单活动运行准入；03 — 交付只读策略预览与一次确认启动。

**Status:** done

- [x] 概览展示运行 ID、环境、策略哈希、开始时间、交易与行情连接、行情新鲜度、每合约精确状态及五档整体阶段。
- [x] 启动中的进程、合约查询、零仓启动门槛、稳定行情等待和进程异常退出都有不同的可理解状态，且 `FAILED` 不会被冒充为进程异常退出。
- [x] 页面关闭、刷新或控制服务重启不结束交易进程；重新连接后从活动运行身份和已有审计恢复概览，每秒更新但不创建第二套交易状态机。
