# 03 — 成交与收口因果链

**What to build:** 让操作者能从单 run 报告追踪一笔报价从首次成交开始，经过价差窗口、对侧成交或受限 FAK、剩余委托撤销和关联查仓，直到本轮结束；成交事实与轮次毛盈亏可直接核对。

**Blocked by:** 01 — 审计因果轨迹到单 run HTML 的最小闭环

**Status:** done

- [x] 首次成交轨迹记录成交委托、成交数量、价格、交易所时间、成交编号和进入收口的原因。
- [x] 价差窗口内对侧成交与窗口超时两条分支分别记录时长、净仓变化、结束原因和后续动作。
- [x] FAK 轨迹记录当时可执行盘口、初始价格、不利 tick 上限、实际价格、重价尝试、拒单或超时结果。
- [x] 平仓终态后剩余报价撤销、关联查仓、净仓结果和本轮完成/失败原因都能在报告中按顺序展示。
- [x] 同一逻辑委托的部分成交、多笔成交和重复回报被正确关联，原始成交明细仍可展开查看。
- [x] 报告展示价差完成或 FAK 平仓的轮次结果，并按既有合约乘数口径计算轮次毛盈亏。
- [x] 覆盖价差窗口内成交、窗口超时 FAK、部分成交、迟到成交和收口失败的本地端到端场景。
