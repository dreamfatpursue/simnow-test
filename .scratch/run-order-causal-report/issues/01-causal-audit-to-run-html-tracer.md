# 01 — 审计因果轨迹到单 run HTML 的最小闭环

**What to build:** 让一个新格式、完整收尾的单合约 run 从状态机决策一路落盘到审计，再由手动单 run 报告命令生成第一份可读 HTML。操作者至少能看到审计品种身份、生效运行参数、逻辑委托摘要，以及首次报价使用的行情和计算详情。

**Blocked by:** None — can start immediately

**Status:** done

- [x] 每个新 run 带可校验的审计格式版本，状态机产生的结构化因果轨迹能随事件和动作安全写入审计日志。
- [x] 首次报价轨迹至少包含当时行情、锚点、pricetick、W、D、距离 tick 数及实际买卖价格。
- [x] 单 run 报告命令能接收一个完整 run，验证新格式和终态摘要，并生成自包含 HTML。
- [x] HTML 展示运行参数、策略哈希、审计品种身份、逻辑委托主表和一个默认收起的报价详情。
- [x] 通过本地确定性事件样例完成“状态机 → 审计目录 → 报告 HTML”高层验证，不连接 SimNow、不发送委托。
