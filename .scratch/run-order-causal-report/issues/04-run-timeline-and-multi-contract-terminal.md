# 04 — 完整运行因果时间线与多合约终态

**What to build:** 让单 run 报告完整展示每个合约从启动安全门槛到终态的运行因果时间线，并在多合约 run 中保持合约、委托、成交和终态严格隔离；成功和失败运行都能被复盘。

**Blocked by:** 02 — 报价撤换因果链；03 — 成交与收口因果链

**Status:** done

- [x] 运行时间线展示合约元数据、启动查仓、零仓确认、稳定行情资格和首次报价门槛。
- [x] 运行时间线展示每轮对账归零、重新进入稳定行情、继续报价、轮数上限、收盘和操作员中断。
- [x] 延迟成交、撤单超时、平仓拒单、平仓超时、非零仓和查询错误等失败路径都有直接原因轨迹。
- [x] 一个多合约 run 自动生成各合约独立的品种身份、参数、运行时间线和逻辑委托表，不发生跨合约串线。
- [x] FINISHED 和 FAILED run 均能生成报告，顶部显示每个合约的终态、轮数、停止原因、失败原因、活动委托和最终净仓。
- [x] 运行级轨迹只展示无法归属单笔委托的变化，委托专属详情不重复堆入运行时间线。
- [x] 覆盖多合约并发、启动非零仓、达到轮数上限、收盘停止、中断和失败终态的本地端到端场景。
