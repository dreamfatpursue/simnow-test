# 06 — 输入门槛、安全与兼容性最终验收

**What to build:** 让单 run 报告达到可交付状态：非法或不完整输入被明确拒绝，审计和 HTML 不泄露凭证，无动作事件不制造解释噪音，现有交易日报告继续工作，并通过完整本地样例验收所有用户可见能力。

**Blocked by:** 04 — 完整运行因果时间线与多合约终态；05 — run 资金结果与可靠盈亏口径

**Status:** done

- [x] 旧审计格式、格式版本不支持、活动中 run、无完整摘要、非终态摘要和缺少必要合约数据均以明确错误和非零退出码拒绝。
- [x] 拒绝输入不会写出看似成功的 HTML，也不会修改原始审计目录。

- [x] 无状态/动作/委托/成交变化的 Tick/Clock 仍保留原始事件，但不出现在运行因果时间线或委托详情中。
- [x] HTML 为自包含单文件，默认详情可展开，可选自动打开；输出稳定写入独立报告目录。
