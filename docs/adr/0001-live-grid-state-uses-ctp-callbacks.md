# 0001. 实时网格状态以 CTP 回报为准

**状态：已采纳**

## 背景

离线回放器可依据历史快照推断模拟成交，但 SimNow 联调会发送真实 CTP 委托。行情穿价既不能证明成交，也不能证明撤单生效；另外，CTP 网关对零持仓查询结果没有现成事件。

## 决策

实时状态机以 CTP 委托、成交和通用持仓查询完成事件推进；该事件携带本次查询汇总持仓及递增 `request_id`，空查询为显式空结果。行情只用于报价、重定锚和盘口保护。首次挂单前必须收到本次查询的目标合约净仓为零；首次部分或全部成交后进入撤单、查仓和受限 FAK 平仓的收口流程。

## 后果

`vnpy_ctp` 作为项目内可追踪的可编辑依赖，需在其中补充一个带 `request_id` 的持仓查询完成事件。不能复用离线回放器的“行情可观察即成交”规则，但可复用 W/D/S 报价与重定锚公式。
