# 价差窗口收口取代立即撤单收口

原语义（单轮成交收口：任一首次成交立即撤销全部剩余委托再对账平仓）是报撤联调测试器的安全设计，但无法观察网格价差的自然完成。决定：首次成交后对侧报价继续挂 `closing_wait_seconds`（默认 1 秒，0 为无窗口）——窗口内对侧成交则价差落袋、直接对账结束；窗口超时则按受限 FAK 平掉净仓、平仓终态后再撤对侧；两条分支都以"全部委托终态 + 对账净仓为零"收尾，保持每轮无遗留委托、无遗留仓位的安全基线。代价是敞口存续时间从亚秒延长到窗口加平仓时长，窗口内/平仓中的对侧迟到成交由既有迟到成交触发兜底。已拒绝的替代方案：平仓后让对侧单跨轮续挂（破坏无遗留委托基线，轮次边界复杂化）。

本 ADR 取代术语"单轮成交收口"的旧定义（立即撤单收口），相关状态机、配置（canonical JSON 与哈希需重新生成）、运行时文档与测试随之调整。
