# 0003. 连续挂单直到收盘时刻

**状态：已采纳**

## 背景

原语义（ADR 0001 及「单次成交收口」）是首次成交后收口并停止整个会话，总暴露天然有界。业务需要改为：每轮"成交→撤单→对账→受限 FAK 平回零仓"完成后继续挂单，直到配置的收盘时刻或操作员中断。备选方案包括不设任何停止条件、或按累计亏损停止。

## 决策

会话在每轮净仓归零后清空锚点、重新通过稳定行情门槛并按当前价重新挂双侧报价。停止条件有三个，按任意先到者生效：配置的 `session_end_time`（本地时钟 HH:MM，到点走与操作员中断相同的收口链路；配置时刻已过当日则视为已收盘立即停止，不支持跨午夜收盘时刻）、`max_round_trips` 轮数上限（默认 10，完成当前轮后正常停止）、操作员中断（随时有效）。轮数用尽与到点停止都是正常终态（FINISHED），以 `stop_reason` 区分；任何收口或平仓失败仍然立即 FAILED 停止该会话，绝不带仓重挂。非收口状态下收到迟到成交（如撤单竞速失败后成交）必须立即触发新一轮收口。

## 后果

总成交手数由轮数上限与时间窗共同约束，单轮暴露不变。轮与轮之间以稳定行情门槛作为天然冷却。旧配置不含新字段时取默认值（不限时刻、10 轮），但"成交即停"的旧语义不再存在；依赖旧语义的测试已改为 `max_round_trips: 1`。审计摘要新增 `round_trips` 与 `stop_reason` 字段。
