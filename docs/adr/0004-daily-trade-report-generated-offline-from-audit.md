# 交易日成交明细 HTML 报告由审计日志离线生成

每个交易日的成交明细 HTML 报告由一个独立的离线命令扫描 `audit/` 下当日全部 run 目录的 `events.jsonl` 与 `summary.json` 聚合生成，而不是由 `run_live_grid.py` 在运行时产出。审计日志是唯一事实源：报告只是它的一种视图，样式或口径调整后可随时重新生成，且完全不触碰实盘下单链路；同一天的多个 run 天然按目录聚合。代价是报告依赖事件里记录的墙钟时间戳（交易所 `InsertTime`/`TradeTime`），补齐该时间戳之前的历史 run 在报告中无法展示挂单/成交时刻。
