# Domain docs

This repository uses a single-context layout.

- Read `CONTEXT.md` at the repository root for domain language and project context.
- Read architectural decisions from `docs/adr/`.
- New ADRs should be added under `docs/adr/` using a numbered Markdown filename.
- There is no `CONTEXT-MAP.md`; do not search for per-module context files unless the repository layout changes.
